# 대학별고사 문항 추출 규칙 (구독 에이전트용)

입력: `C:\tmp\interview-bank\jobs\<작업>.txt` — 대학 '선행학습 영향평가 자체평가보고서'에서 문항카드 관련 쪽만 뽑은 텍스트. `<<쪽 N>>` 이 쪽 번호.
출력: `C:\tmp\interview-bank\out\<작업 이름에서 .txt 를 .json 으로>` — 아래 모양의 JSON 하나(UTF-8). 다른 파일은 만들지 않는다.

```json
{ "university": "경희대학교", "questions": [ {
  "kind": "논술" | "면접",
  "qno": "문서에 적힌 문항 번호·이름 그대로(예: 인문・체육계열 논제 Ⅰ, 자연계열 오전 [문제 2])",
  "question": "학생이 답해야 하는 질문·논제 원문(하위문항 [1-1] 등 번호 살려 함께). 이 작업 파일에 질문 원문은 없고 근거만 있으면 \"\"",
  "passage": "제시문·자료 원문(없으면 \"\", 5000자까지). 깨진 수식·그림은 [수식] [그림]",
  "dept": "모집단위·계열(문서 표기, 없으면 \"\")",
  "track": "전형명(없으면 \"\")",
  "interviewType": "제시문 기반|서류 기반|인성|MMI|교직적성|전공적성|기타|해당없음(논술)",
  "essayField": "인문|사회|인문사회 통합|수리|과학|의학|기타|해당없음(면접)",
  "subject": "관련 교과·과목 한 줄",
  "intent": "출제 의도 요약 200자 이내(문서에 있을 때만)",
  "followUps": ["면접 꼬리 질문"],
  "evalPoints": "채점 기준·예시 답안의 핵심 요지 600자 이내 — 무엇을 쓰면 점수가 나는지",
  "curriculum": [ { "subject": "과목명", "code": "[12수학Ⅱ02-03]", "standard": "성취기준 문장 150자 이내" } ],
  "units": ["통합사회 · 사회 변화와 공존"],
  "textbooks": [ { "title": "도서명", "publisher": "출판사", "pages": "쪽" } ],
  "page": 33
} ] }
```

규칙
- 논술고사 문항과 면접·구술고사 문항(제시문 면접 포함)만. 적성고사·실기·수능·일반 지필 문항, 위원회 검토의견서·운영 절차·통계는 넣지 않는다.
- 질문·제시문·성취기준 코드와 문장은 **원문 그대로** 옮긴다(PDF 추출로 깨진 띄어쓰기·줄바꿈만 바로잡음). 지어내거나 요약해서 바꾸지 않는다. 나중에 컴퓨터가 원문 대조를 한다.
- curriculum·textbooks·units 는 문항카드의 «관련 성취기준», «자료 출처/교과서», «적용 교육과정·교육과정 근거» 칸에 적힌 것만. 없으면 빈 배열.
- 한 문항의 질문과 근거가 이 파일 안에서 떨어져 있으면 한 항목으로 합친다. 질문이 이 파일에 없고 근거만 있으면 question 을 "" 로 두고 qno 를 문서 표기 그대로 적는다(다른 파일의 질문과 나중에 잇는다).
- 같은 질문이 두 번 나오면 한 번만, 더 자세한 쪽으로.
- 문항이 하나도 없으면 `{"university": "...", "questions": []}`.
- 파일이 길면 Read 를 offset/limit 로 나눠 끝까지 읽는다. 다 쓴 뒤 `python -I -X utf8 C:\tmp\interview-bank\check_out.py <출력 파일>` 로 검사하고, 오류가 나오면 고친다.

## 보충 작업(jobs/G*.txt) 추가 규칙
- 보충 파일은 앞 작업에서 빠졌던 쪽만 모은 것이다. 여기서 중요한 것은 **질문·논제 원문과 제시문**이다. 질문 원문이 있으면 반드시 넣고, qno 를 문서 표기 그대로 적는다(다른 파일의 근거와 이 번호로 잇는다).
- 같은 쪽에 성취기준·채점 기준이 있으면 함께 넣는다. 질문 없이 근거만 있는 조각은 넣지 않아도 된다(이미 다른 파일에 있음).
- 보조 스크립트를 만들면 C:\tmp\interview-bank\wG\ 폴더 안에 작업 이름을 붙여 만든다.

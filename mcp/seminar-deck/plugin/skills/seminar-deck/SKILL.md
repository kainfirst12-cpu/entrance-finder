# 설명회 자료 만들기 (seminar-deck MCP)

입시파인더 웹의 📽️ 설명회 자료 만들기와 같은 엔진·같은 데이터로 PPT를 만든다. 도구는 `seminar-deck` MCP 서버가 제공한다.

## 순서

1. **`seminar_status`** 를 먼저 부른다.
   - `loggedIn: false` → 원장에게 입시파인더 **학원 코드**를 물어 `seminar_login` 에 넣는다. 코드는 대화에 다시 적지 않는다.
   - `seminarMenu: false` → 이 학원 코드에는 설명회 메뉴가 안 열렸다. "입시파인더 관리자에게 설명회 메뉴를 열어 달라고 요청해 주세요"라고 안내하고 멈춘다.
   - `savedDecks` 가 있으면 "지난번 ○○ 자료로 만들까요, 새로 고를까요?"를 묻는다.
2. **담당 학교 고르기**
   - 학교 이름을 말하면 `find_schools`(줄임말 그대로: 부천여고·상동고). `ambiguous` 가 있으면 후보 지역을 보여 주고 고르게 하거나, 이미 고른 학교들과 같은 지역으로 `region` 을 넣어 다시 찾는다.
   - "부천 일반고 전부"처럼 말하면 `region_schools`(sido·sigungu).
3. **`analyze_schools`** 로 분석을 보고 원장에게 짧게 요약한다: 학교 수, 공시 학년도, 성취도 층(상위권·중위권·기초 보완) 묶음, 과목별 강세 학교. `skipped`(공시 없는 학교)가 있으면 알린다.
4. **해설 문구(선택, 권장)** — 학교마다 `factsForNotes` 수치를 근거로 직접 쓴다.
   - `subjects`: 과목별 한 줄, "평균 높고 편차 낮음 → 상·중위권이 고르게 분포한 안정형 과목" 꼴, 40자 이내. 키는 국어·수학·영어·한국사·통합사회·통합과학.
   - `strong` / `weak`: 과목 이름 하나(국어·수학·영어·사회·과학·한국사) 또는 null.
   - `typeLine`: "상위권 안정 / 수리·탐구형" 꼴. **층(상위권 안정·중위권 성장형·기초 보완형)은 분석 결과 그대로** 둔다.
   - 숫자·분류는 절대 바꾸지 않는다. 없는 사실(대학 실적·순위)을 지어내지 않는다. 학교를 깎아내리지 않는다(하위권이 많으면 '기초 보완이 중요'). 과장·보장 표현 금지. 학부모는 '학부모님'.
5. **설정 확인** — 아래를 원장에게 한 번에 묻고 기본값을 제안한다.
   - 표지: 큰 제목(예: 2027 고입 및 2030 대입 설명회)·장소·날짜
   - ① 제도 설명 공통본 넣기(`includeCommon`, status 의 `publishedCommon` 이 '없음'이면 못 넣는다)
   - ③ 우리 학원 소개 넣기(`includeAcademy`, status 의 academy 가 '저장 전 처음 모양'이면 웹에서 다듬어 저장하길 권한다)
   - 학교별 파트 번호·제목(공통본을 넣으면 자동으로 다음 번호)
   - 표지·감사 장의 학원 이름·로고가 status `brand` 에 없으면 `set_brand` 로 넣는다(로고는 파일 경로).
6. **`save_deck`** 으로 웹에 저장한다(같은 묶음을 웹에서도 열 수 있다). 고치는 중이면 id 를 넣어 덮어쓴다.
7. **`build_pptx`** (deck_id 와 options·notes)로 파일을 만든다. 돌려받은 `file` 경로와 슬라이드 수, `parts` 를 알린다.
   - Cowork 에서 사용자 폴더가 정해져 있으면 `out_dir` 로 그 폴더를 준다. 아니면 기본 폴더(문서\설명회자료).
8. 학부모님께 보낼 거면 **`share_link`** — 로그인 없이 휴대폰으로 보는 링크. "만든 순간의 슬라이드라 고친 뒤엔 새 링크를 만들어야 한다"고 알린다.

## 알아 둘 것

- 분류(강세·성취도 층)는 **함께 고른 학교들끼리** 비교한 결과다. 학교 묶음이 바뀌면 같은 학교도 달라질 수 있다고 원장에게 한 번 알린다.
- 2025학년도부터 학교알리미에 표준편차가 없어, A~E 에 점수를 매긴 **상대 표준편차**를 쓴다(슬라이드에도 적혀 있다).
- 학교마다 그 학교의 **가장 최근 공시 학년도**를 쓴다. 새 공시가 입시파인더에 반영되면 같은 자료를 다시 만들기만 하면 숫자가 바뀐다.
- PPT 안의 표·차트는 진짜 표·차트라 파워포인트에서 바로 고칠 수 있다. 그림 자리(작년 자료의 캡처 등)는 원장이 직접 붙인다.
- 공통본 편집·발행과 학원 소개 편집(사진 올리기)은 웹 화면에서 한다. 이 도구는 읽어서 붙이기만 한다.
